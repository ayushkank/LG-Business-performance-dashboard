
# LG Business Performance Dashboard

A simple and interactive business dashboard built using HTML, CSS, JavaScript and Chart.js to visualize business performance from January to June.

## 📌 Project Overview

The dashboard provides a quick overview of the company's financial performance through interactive charts and KPI cards. It helps track revenue, expenses, profit and monthly performance in one place.

## 🛠️ Tech Stack

- **HTML5** – Structure of the dashboard.
- **CSS3** – Styling, responsive layout and dark/light themes.
- **JavaScript** – Data handling, calculations and interactivity.
- **Chart.js** – Creating interactive charts and visualizations.

## 📊 Features & Highlights

- **KPI Cards:** Displays total revenue, total expenses, total profit and best-performing month.
- **Line Chart:** Compares monthly revenue, expenses and profit.
- **Bar Chart:** Visualizes revenue across six months.
- **Pie Chart:** Shows the distribution of June's revenue.
- **Dark/Light Mode:** Allows users to switch between themes.
- **Interactive Tooltips:** Displays exact values when hovering over charts.
- **Responsive Design:** Adapts to desktop and mobile screens.
- **Indian Currency Format:** Displays financial figures in INR (₹).

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. The dashboard will load automatically.

**Note:** An internet connection is required initially to load Chart.js from its CDN.

## ⚙️ Customization

The dashboard can be customized by editing the JavaScript variables inside `index.html`:

- `months` – Change the displayed months.
- `revenue` – Update monthly revenue figures.
- `expenses` – Update monthly expenses.
- `profit` – Update monthly profit.
- Pie chart labels and values – Modify June's revenue distribution.

The dashboard automatically updates the KPI cards and the first two charts based on the updated monthly data.
